This repository keeps the former GitHub Pages addresses working after the site moved.

- https://sowarden.github.io/ redirects to https://undergrnd.dev/.
- https://sowarden.github.io/nck.html redirects to https://undergrnd.dev/nck.html.

The pages use an immediate HTML refresh, a JavaScript history replacement, a canonical
URL and a visible fallback link. They do not forward query parameters or load the
old calculator. GitHub Pages serves these static pages; this is not an HTTP 301.

Existing verification files and legacy assets are retained. The HH71VM project
repository remains https://github.com/sowarden/hh71vm-openwrt.
